# Current State — sala

**基准日期：2026-10-18；状态：进入工程原型开发。**

## 项目身份

- 仓库：`mattamior/sala`，权威分支：`main`；项目代号/暂定名称：**sala**（偏好小写）。
- 产品定位：计划开源、易上手、高自由度的 **AI 原生视频创作 Agent**，同时支持图片创作和图片/视频参考素材。
- 目标用户：并非仅限开发者或这台本地 Mac 的拥有者；希望普通用户下载应用、配置所需模型/服务即可创作。Agent 的 LLM URL + API Key 配置是简单入门的一部分，**不意味着一个 LLM API 需要承担所有生图/生视频能力**。
- 当前已建立可运行的 **Python 3.11+ / FFmpeg 工程原型**（`src/sala/`；`DEV.md`），支持明确时间范围的视频截取、提帧、作品修订记录、预览与拒绝不能满足的保留约束。可选的 OpenAI 兼容 LLM 单动作解析接口仅经过模拟服务测试。**还没有完整自主创作 Agent、生成式视频链、桌面 UI 或正式发布技术栈。**

## 已确认的创作理念

- Agent 主导理解、内部分析、工具选择和执行；用户主要通过自然语言表达、确认和反馈。
- 同时允许“一句话自动创作”和持续协作迭代；复刻任务严守参考与保留约束，开放任务允许 Agent 发挥创意；可按不同创作维度分别定义自由度。
- 当意图存在关键歧义时，**倾向先澄清、再正式执行**；澄清应低负担，优先用直观问题、候选图/预演等交流手段。
- 使用指认、比较、选择等**可视化抓手**建立共同语境，而非首先提供传统时间线、关键帧编辑器和节点编辑器。
- 对局部修改追求最小必要变更：清楚区分改动目标、必须保留的部分、边界和复核标准；支持参考素材的高精度复刻。
- 白模/灰模动态预演、以及从参考视频重建空间布局与运动的能力具有潜力，但真实性能与可实现范围尚未验证，**不是已承诺的 V1 功能**。
