## Implementation
- `src/sala/planner.py`：同时接受 API base `/v1` 和完整 Chat Completions 路径；结构化 JSON/fenced-JSON 支持；模型澄清/不支持区分；401/403、402、429、5xx 错误归类；不传 `temperature`。
- `src/sala/session.py`：模型请求澄清或报告当前不支持时，将其保存为 `needs_clarification` 会话状态。
- `src/sala/cli.py`：增加 `doctor llm` 只读在线诊断命令。
- `tests/test_llm_m22.py`：使用模拟 HTTP 响应验证模型请求结构、解析、错误、鉴权信息不泄漏、会话澄清等。
