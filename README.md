# sala

**sala** 是一个处于产品探索阶段的、计划开源的 AI 原生视频创作 Agent。

> Create through conversation.（暂定产品文案，不是已确认的品牌规范。）

用户用自然语言与参考图片、参考视频表达创作意图；Agent 负责理解、澄清、规划、选择并调用创作工具，用户通过少量直观的视觉反馈参与创作决策。目标是降低创作门槛，同时为高级用户保留高度自由度。

> **状态：早期开发 / 可运行工程原型。** 已有 Python + FFmpeg 命令行切片和可选的受限 LLM 指令规划接口；这不是完整 Agent、桌面应用或媒体生成产品。开源许可证、品牌可注册性和发布计划尚未确定。

## 已达成的产品共识

- 面向广泛用户的易用开源产品，而不是仅供维护者使用的本地 AI 工作站。
- 自然语言为主要入口；图片与视频可作为参考输入，支持高精度复刻与迭代修改。
- Agent 可自动创作，也可与用户协作；自主性随创作维度和用户约束变化。
- 对含混的关键意图，先低成本澄清再正式执行，而非擅自消耗生成资源。
- 提供用于指认、比较、选择的**可视化沟通抓手**，不是优先建设传统专业剪辑时间线。
- 预演、白模、从参考视频分析/重建空间与运动的能力值得探索；其具体可行性未定。
- LLM 连接配置与图片/视频生成后端配置是**不同的能力**，并未规定单个 LLM API 必须完成所有任务。

## 开发状态

**已进入开发阶段。** 第一个可运行切片实现明确的自然语言截取/提帧、FFmpeg 执行、输出验证和作品版本/历史记录；同时提供可选的 OpenAI 兼容 LLM 单步规划接口。详细运行方式及局限见 [DEV.md](DEV.md)。

目前 Python 是快速验证的**原型实现选择**，不是正式跨平台架构定案。尚无自动视频生成、多轮自主规划、参考复刻或桌面 UI。OpenCode、Pi、Ollama、ComfyUI、Draw Things、MCP 等仍为后续候选，避免把研究讨论当成实现。
